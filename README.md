# Ronel B. Glodove — Web Developer Portfolio

A responsive student portfolio built with plain HTML, CSS, and JavaScript, following the provided *Website Portfolio Student Guide*.

## Files
- `index.html` — homepage and portfolio sections
- `style.css` — responsive styling
- `script.js` — mobile navigation and footer year
- `assets/` — add your own project screenshots here if desired

## Personalize before publishing
1. Replace every `YOUR_USERNAME` with your GitHub username.
2. Replace `YOUR_EMAIL@example.com` and the contact placeholder with an email address you are comfortable publishing.
3. Check that the project descriptions accurately represent your contribution.
4. Add screenshots you own or have permission to publish. Update the project cards to use them if you want.
5. Remove any skills or project details that do not reflect your actual experience.

## Preview locally
Open `index.html` in a browser, or use the VS Code Live Preview extension.

## Publish with GitHub Pages
1. Create a public GitHub repository named `portfolio`.
2. Upload the contents of this folder (not the ZIP itself) so `index.html` is at the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/(root)`, then save.
6. After deployment, your website will usually be available at:
   `https://YOUR_USERNAME.github.io/portfolio/`

Use the actual URL shown by GitHub Pages. Test it in a private/incognito browser window and on your phone.
